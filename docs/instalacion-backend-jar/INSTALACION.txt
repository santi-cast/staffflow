==============================================================================
StaffFlow — Backend como JAR ejecutable
==============================================================================

Esta carpeta contiene el backend de StaffFlow empaquetado como JAR
ejecutable. Pensada para quien tiene Java 21 instalado pero no quiere
abrir el proyecto en un IDE.

El backend arranca en el perfil "dev": base de datos H2 en memoria con
datos demo precargados, login de prueba listo para usar.


------------------------------------------------------------------------------
1. Requisitos
------------------------------------------------------------------------------

- Java 21 instalado (Eclipse Temurin, OpenJDK, Oracle JDK o equivalente).
  Verificar con:  java -version
  Tiene que mostrar version 21 o superior.

- Puerto 8080 libre en el equipo (si otra aplicacion lo esta usando,
  habra que detenerla antes).

- ~250 MB libres de RAM mientras el backend este en ejecucion.


------------------------------------------------------------------------------
2. Arranque
------------------------------------------------------------------------------

Desde una terminal, situarse en esta carpeta y ejecutar:

    java -jar staffflow-backend.jar

El arranque tarda unos 5-10 segundos. Cuando aparezca el mensaje
"Started StaffflowBackendApplication" el backend esta listo.


------------------------------------------------------------------------------
3. Acceso
------------------------------------------------------------------------------

- API REST:        http://localhost:8080/api
- Swagger UI:      http://localhost:8080/swagger-ui/index.html
- Estado salud:    http://localhost:8080/api/health

Credenciales de prueba (rol ADMIN):

    Usuario:    admin001
    Contrasena: admin1234

Otras credenciales demo:

    usu001 / user1234   (rol ENCARGADO)
    usu002 / user1234   (rol EMPLEADO)
    usu003 / user1234   (rol EMPLEADO)


------------------------------------------------------------------------------
4. Detener
------------------------------------------------------------------------------

Pulsar Ctrl+C en la terminal donde se ejecuto el comando.

Como el perfil "dev" usa base de datos H2 en memoria, al detener el
backend se pierden los cambios realizados durante la sesion. Al volver
a arrancar el JAR los datos demo originales vuelven a cargarse desde
cero.


------------------------------------------------------------------------------
5. Notas
------------------------------------------------------------------------------

- El JAR incluye todas las dependencias (es un "fat JAR" de Spring Boot).
  No hace falta instalar Maven ni descargar librerias adicionales.

- Para conectar la aplicacion Android al backend desde otro dispositivo,
  ver las instrucciones en docs/instalacion-android/INSTALACION.txt
  (apartado "Configurar URL del backend").

- El envio de correos (endpoints de recuperacion de contrasena) requiere
  credenciales SMTP reales que NO vienen configuradas en el JAR. Sin
  ellas, los demas endpoints funcionan correctamente pero los envios de
  email fallaran en tiempo de ejecucion.
