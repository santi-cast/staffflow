==============================================================================
StaffFlow — Aplicacion Android (APK)
==============================================================================

Esta carpeta contiene el APK de la aplicacion Android de StaffFlow.
Pensada para instalar la app en un dispositivo fisico o emulador sin
necesidad de Android Studio.

La aplicacion requiere un backend de StaffFlow accesible en la misma
red. Antes de instalar el APK conviene tener el backend arrancado segun
docs/instalacion-backend-jar/INSTALACION.txt o
docs/instalacion-backend-docker/INSTALACION.txt.


------------------------------------------------------------------------------
1. Requisitos
------------------------------------------------------------------------------

- Dispositivo Android 7.0 (API 24) Nougat o superior.
- ~50 MB libres en el almacenamiento interno.
- Permiso para instalar aplicaciones de origenes desconocidos
  (la ruta exacta depende de la version de Android; tipicamente en
  Ajustes > Seguridad o Ajustes > Aplicaciones > Acceso especial).
- Backend de StaffFlow arrancado y accesible en la MISMA red WiFi que
  el dispositivo Android.


------------------------------------------------------------------------------
2. Instalacion
------------------------------------------------------------------------------

1. Copiar el archivo staffflow-android.apk al dispositivo (via cable
   USB, correo electronico, descarga o cualquier otro metodo).

2. Abrir el archivo desde el explorador de ficheros del dispositivo.

3. Confirmar la instalacion cuando Android lo pida. Si aparece un aviso
   de origen desconocido, conceder el permiso al explorador o al
   navegador desde el que se abre el APK.

4. Una vez instalada, la aplicacion aparece en el lanzador con el icono
   y el nombre "StaffFlow".


------------------------------------------------------------------------------
3. Configurar URL del backend
------------------------------------------------------------------------------

La primera vez que se abre la aplicacion hay que indicarle donde esta
el backend. El proceso tiene dos partes: averiguar la IP del equipo
donde corre el backend e introducirla en la app.

3.1 Averiguar la IP del equipo donde corre el backend

  Windows:    abrir CMD y ejecutar    ipconfig
              Buscar la linea "Direccion IPv4" de la red WiFi activa
              (ejemplo: 192.168.1.42).

  macOS:      abrir Terminal y ejecutar    ifconfig | grep "inet "
              Buscar la IP de la interfaz en0 o en1 (ejemplo:
              192.168.1.42), ignorando 127.0.0.1.

  Linux:      abrir terminal y ejecutar    ip addr show
              Buscar la linea "inet" bajo la interfaz WiFi activa
              (tipicamente wlan0 o wlp3s0), ejemplo: 192.168.1.42.

3.2 Introducir la URL en la app

  1. Abrir la aplicacion StaffFlow.
  2. En la pantalla de inicio de sesion, tocar el icono de
     configuracion (engranaje) situado en la esquina superior.
  3. Introducir la URL completa con el formato:

         http://IP:8080

     Sustituyendo IP por la direccion obtenida en el paso 3.1.
     Ejemplo:    http://192.168.1.42:8080

  4. Tocar el boton "Probar conexion". Si el backend responde, la app
     guarda la URL y vuelve a la pantalla de login.

La URL queda almacenada en el dispositivo (en DataStore). Solo hace
falta configurarla una vez; en arranques posteriores la app se conecta
automaticamente al mismo backend.

Para cambiar la URL mas adelante (por ejemplo, si el backend cambia de
equipo) basta con volver al icono de configuracion desde la pantalla de
login y repetir el proceso.


------------------------------------------------------------------------------
4. Credenciales de prueba
------------------------------------------------------------------------------

Una vez configurada la URL, iniciar sesion con cualquiera de los
usuarios demo precargados en el backend:

    Usuario:    admin001     Contrasena: admin1234     (rol ADMIN)
    Usuario:    usu001       Contrasena: user1234      (rol ENCARGADO)
    Usuario:    usu002       Contrasena: user1234      (rol EMPLEADO)
    Usuario:    usu003       Contrasena: user1234      (rol EMPLEADO)


------------------------------------------------------------------------------
5. Notas
------------------------------------------------------------------------------

- El backend tiene que estar arrancado ANTES de abrir la aplicacion. Si
  el backend esta apagado, la pantalla de login mostrara error de
  conexion.

- El equipo donde corre el backend y el dispositivo Android tienen que
  estar conectados a la MISMA red WiFi. Si estan en redes distintas
  (por ejemplo, dispositivo en datos moviles y equipo en WiFi
  domestica), la app no podra alcanzar el backend.

- El cortafuegos del equipo donde corre el backend debe permitir
  conexiones entrantes en el puerto 8080. En Windows Defender o en el
  cortafuegos de macOS aparece un aviso la primera vez que el backend
  arranca: hay que conceder el permiso para la red privada.

- Para usar la app con el emulador de Android Studio en lugar de un
  dispositivo fisico, la URL del backend es    http://10.0.2.2:8080
  (10.0.2.2 es la IP especial que el emulador usa para acceder al
  equipo anfitrion). La app detecta este caso automaticamente la
  primera vez si no se configura URL manual.
